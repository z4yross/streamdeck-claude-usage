## Name

Claude Usage

## Description

Keep an eye on your Claude Code plan without leaving your work. Claude Usage puts both rate-limit windows, the 5-hour and the 7-day one, on a Stream Deck+ dial, each with a progress bar and the time left until it resets. Bars turn green, amber and red as a window fills up.

Tap the dial for a prediction: at your current pace, the time the window hits 100%, or the percent it lands on at reset if it does not. Tap again to cycle the second row through the 7-day windows the API reports, per model. Hold the dial to open the usage page at claude.ai.

Several accounts? Each one is a Claude Code config directory. Rotate the dial to switch between them. There is no extra login: the plugin reads the OAuth token Claude Code already keeps, and backs off any account that fails so a dead token never rate-limits the live ones.

Requirements: Windows 10 or later, a Stream Deck+, and Claude Code installed and logged in. Free and open source.
